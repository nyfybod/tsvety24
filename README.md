# Цветы24

Самостоятельный статический сайт. Откройте index.html в браузере или запустите `python -m http.server 8000` в этой папке. Сборка и установка пакетов не нужны. Для публикации нужны index.html, styles.css, script.js, favicon.svg и assets/.

Каталог: 54 товаров с соответствующими фотографиями и ценами. Услуги, шесть пересказов отзывов, галерея, фильтры, бюджет, сортировка, просмотр фотографий, звонок и переход на карту.

Источник: https://yandex.ru/maps/org/165257773473/, дата проверки 09.11.2026. data/content.json — отображаемые факты; data/products-source.json — исходный прайс. Стоимость и наличие требуют подтверждения магазина. Отзывы — краткие пересказы с именами, датами и ссылками. Указан реальный общий рейтинг; не все исходные отзывы положительные. Тариф доставки не придуман. Прайс помечен Яндексом как давно не обновлявшийся.

Исходный Rose73 послужил образцом структуры и взаимодействий. Этот сайт независим от него: свои тексты, фото, контакты, товары и оформление. При переносе папки соседние проекты не требуются. Внешний ресурс оформления — Google Fonts с локальными шрифтовыми fallback.
